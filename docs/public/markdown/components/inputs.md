# Inputs

::: tip Look concreto
Esta página define el **contrato** (propósito, estados y reglas). El aspecto
exacto, con medidas, colores y código, está en el
[catálogo de componentes](/catalog/atoms/inputs).
:::

## Supported patterns

- Text field
- Password field
- Search field
- Textarea
- Select
- Checkbox
- Radio group
- Switch

## Anatomy

A field should include a label, control, optional hint, and validation message. Placeholder text is not a replacement for a label.

## States

Default, hover, focus-visible, filled, disabled, read-only, invalid, and loading where applicable.

## Rules

- Keep labels persistent.
- Explain format requirements before or beside the field.
- Associate errors programmatically with the control.
- Preserve entered values when validation fails.
- Do not communicate validation only through a red border.
- Use native controls where they provide better accessibility and platform behavior.
