# Product expression

MXNI supports multiple product types while retaining a shared foundation.

## Shared across all products

- Core typography.
- Core color roles.
- Spacing and geometry scale.
- Interaction and accessibility principles.
- Brand signature and visual language.

## Allowed to vary

- Information density.
- Product-specific semantic colors.
- Navigation model.
- Data visualization palette extensions.
- Photography and illustration.
- Component composition based on product tasks.

## Product families

| Family | Priority | Expression |
|---|---|---|
| Web | Brand and storytelling | Spacious, editorial, Bento |
| Software | Task completion | Functional, clear, balanced |
| Media | Attention and narrative | Expressive, high contrast |
| Docs | Retrieval and comprehension | Structured, readable, technical |

A product may add tokens, but additions must be named, justified, and documented.

## Platforms

Product families describe the purpose of a product; platforms describe where
it runs. Apply the guide for each platform the product ships on:
[Web](/platforms/web/), [Desktop](/platforms/desktop/) and
[Mobile](/platforms/mobile/).
