# Escritorio: checklist de revisión

Usa esta lista antes de dar por terminada una interfaz de escritorio. Los
agentes de IA deben reportar cada punto.

## Marca y tokens

- [ ] Colores, tipografía, espaciado y radios salen de los tokens MXNI.
- [ ] Los acentos se usan con moderación (5–10 % de la composición).
- [ ] El logo es el SVG oficial con sus colores originales.

## Ventana y layout

- [ ] La ventana tiene tamaño mínimo y el layout se adapta al redimensionar.
- [ ] Se guardan y restauran tamaño, posición y paneles.
- [ ] Los controles de ventana respetan la convención del sistema operativo.
- [ ] Se ve bien a escala de pantalla 100 %, 150 % y 200 %.
- [ ] La densidad corresponde al tipo de producto.

## Navegación y comandos

- [ ] La navegación principal es persistente y marca la ubicación actual.
- [ ] Las acciones frecuentes tienen atajo y el atajo se muestra.
- [ ] Los atajos estándar del sistema no se reasignan.
- [ ] Todo lo que hay en un menú contextual existe en otro lugar accesible.

## Accesibilidad

- [ ] Todo es operable con teclado y el foco es visible.
- [ ] Los controles exponen nombre, rol y estado al sistema.
- [ ] El color nunca es la única señal de estado.
- [ ] Contraste AA verificado.
- [ ] Se respetan movimiento reducido y alto contraste.
- [ ] Arrastrar y soltar tiene alternativa.

## Robustez

- [ ] La interfaz no se congela en tareas largas.
- [ ] No se pierden cambios al cerrar.

## Reporte del agente

- Plataforma: **escritorio** (y sistemas operativos objetivo).
- Tokens usados.
- Componentes y patrones reutilizados.
- Comportamiento al redimensionar.
- Atajos definidos.
- Consideraciones de accesibilidad.
- Desviaciones o adiciones propuestas.
